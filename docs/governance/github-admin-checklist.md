# GitHub 管理员配置清单

本清单记录后续仓库管理员需要在 GitHub 仓库设置中完成的治理配置。Phase0 不会自动强制执行以下设置；在配置完成前，团队仍须按开发协作标准进行人工审查。

## 分支保护

- 对 `main` 启用 Pull Request 合并要求，禁止直接推送。
- 要求至少一名评审者批准后才能合并。
- 将 `lint`、`build`、`test` 和 `check:repository` 配置为必需检查，并确认其状态来自受信任的 CI 工作流。
- 禁止 force push。
- 限制绕过分支保护的人员和自动化主体；仅在明确授权、可审计的紧急情形下允许绕过。

## 可选责任归属

- 可选启用 CODEOWNERS 审查要求，用于高风险目录或跨团队边界。
- 启用前，将 `.github/CODEOWNERS.example` 复制并维护为实际的 `CODEOWNERS`，替换所有示例团队账号。
- 定期确认责任团队、分支保护例外和必需检查仍然有效。

## 配置后的验证

- 使用测试 PR 确认未获批准、必需检查失败和 force push 均无法合并或推送。
- 记录管理员配置日期、责任人和例外审批依据。
