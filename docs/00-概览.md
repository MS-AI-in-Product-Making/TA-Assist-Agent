## 是什么

TA 助手 Agent 使 Microsoft ME 团队和 ODM 合作伙伴的 PD 团队能够交付高质量的公差分析。

它通过针对已识别的公差链，自动审查 TA 输入的合理性；从 TA 结果中生成基于证据的洞察；并通过迭代 TA 周期推动所提议且已关联的尺寸要求，从而支持有效的风险缓解和 OK2Ramp 决策。

1. **数据解读**：对 TA 输出进行客观、以证据为基础的解读；每一条 `RULE` 都可追溯至知识库条目，最终判断仍由工程师做出。
2. **交互式 TA**：工程师参与调整假设、重新运行分析、比较方案，并逐步收敛到风险缓解行动。

它将以电子表格为主、手工执行的 TA 工作升级为具备可审计证据的质量驱动型工程工作流。

## 为什么

随着产品转向 RDM 模式，依赖有限 ODM 工程带宽进行手动数据录入和分析的传统 TA 工作流，已无法支持高频、多层叠加和迭代分析的需求。
挑战不再只是速度：在里程碑压力下，TA 质量和工程决策信心面临越来越高的风险：

- **链路断裂**：尺寸链、图纸关联和真实测量数据可能逐渐脱节，从而降低对 TA 结论的信心。
- **问题发现过晚**：DIM 关联缺失和尺寸链断点常在关键里程碑（例如 EV1）临近时才被发现。
- **决策支持不足**：静态报告无法有效支持快速的 What-if 仿真和基于证据的工程判断。

此外，通用 LLM 不足以直接支持 TA 决策：它们无法原生执行 Microsoft 与供应商的工程规则或零件类别能力库，也无法稳定地提供可逐行核查的证据。

该工具的目标是将 TA 从临时性执行转变为质量有保障、由工程师主导的决策工作流。

## 如何实现

系统将受控知识库与和 Excel 一致的计算引擎相结合，并通过 ADO 和服务端能力进行端到端编排：

- **尺寸质量关卡**：在分析前和关键里程碑评审前，验证“已提议且已关联”尺寸的质量。
- **交互式 TA 闭环**：运行 WC/RSS 计算，基于规则和能力证据提供解读，并支持工程师调整后重新运行和比较。
- **可追溯证据链**：通过 DIM ID 关联 TA 因子、图纸尺寸、规则依据和真实测量结果。
- **运营集成**：工程师上传 TA `.xlsx` 文件，并可创建 ADO 工作项；工具基于上传文件运行，从 ADO 字段解析负责人并发送里程碑前提醒。（直接从 ADO 附件自动解析 `.xlsx` 属于后续目标；当前仍由用户手动上传文件。）
- **实测数据反馈校准**：按 DIM ID 回填实测 Cpk，对比“估算值与实际值”，并持续提升后续判断的准确性。

## 业务价值

- ✅ **更快**：TA 周期从数小时降至数分钟。
- ✅ **成本更低**：减少手动清洗、复核和重复跟进。
- ✅ **更稳健**：更早暴露风险，减少关键里程碑前的意外。
- ✅ **可追溯**：DIM ID 将设计、分析、提醒和实测结果串成一条可追溯链路。
- ✅ **更易管理**：ADO 工作项和服务端提醒减少流程断点。
- ✅ **持续增益**：实测数据持续回填，不断提高能力判断的准确性。
