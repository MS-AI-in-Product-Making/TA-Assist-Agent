# F8 UI-OP1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 F8 的受治理数据映射、图片身份和术语问题，并把界面重组为可同屏调整与观察结果的 TA analysis cockpit。

**Architecture:** 先在 F1/F2/F4 数据链中补齐 worksheet-level Design Nominal，再把 F1 image 请求从 hash-only 改为 worksheet-bound identity。Web model 只投影 F2/F4/F5 已验证字段，canonical table 与 sticky live-analysis cockpit 消费同一 model，不在组件内派生工程术语。

**Tech Stack:** TypeScript, React 19, Fastify, Zod, Vitest, Playwright, CSS Grid

**Spec:** `docs/superpowers/specs/2026-08-31-f8-ui-op1-design.md`

## Global Constraints

- Web 只展示 F1/F2/F3/F4/F5/F6 已验证字段，不自行发明工程术语、数值或图片到 factor 的映射。
- `Design Nominal`、`Lower Spec Limit`、`Upper Spec Limit`、`Mean Response`、`Additional Mean Shift` 必须保持 Excel/F2/F4 原始语义。
- Loop Label 只能来自 F5 v2 structured `linkedVisualLabels`；无映射显示 `Not available`。
- 相同图片 hash 可服务于不同 worksheet，但每次请求必须绑定当前 F2 artifact、worksheet、relative path 和 hash。
- 工作簿只读；What-if 继续使用 F4 kernel，不回写 Excel。
- 不新增外部 UI 依赖；保持现有 Material 3 token。
- desktop/mobile 不允许页面级横向 overflow；宽表仅在局部容器滚动。
- 保留当前分支中尚未提交的 ADO 实时进度修改。
