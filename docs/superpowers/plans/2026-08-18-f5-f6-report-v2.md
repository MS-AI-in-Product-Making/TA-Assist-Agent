# F5/F6 TA Report V2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 F6 升级为 target-driven optimization v2，并生成中文、16 章、证据与公式可复核的 F5+F6 TA 联合报告。

**Architecture:** F4 `excel-ta-v1` 保持唯一 baseline/scenario 计算真源；F6 新增严格的 Analysis Context 与 Optimization Targets 输入、target-driven scenario 生成和 report projection adapter。Composed builder 只组织 F2-F6 已验证数据及受控 derived report metrics，renderer 不执行工程计算；F6 保持六文件同名原子发布。

**Tech Stack:** TypeScript、Zod、Node.js ESM、Vitest、F4 calculation kernel、Markdown/JSON artifacts、PowerShell/Windows

**Spec:** `docs/superpowers/specs/2026-08-18-f5-f6-report-v2-design.md`

## Global Constraints

- `contractVersion` 公共 envelope 继续为 `v1`；当前 F6 artifact 版本改为 `f6-optimization-v2`、`f6-composed-report-v2`。
- 当前入口拒绝 F6 v1 artifact，返回受控 `unsupported_artifact_version`，不隐式迁移。
- Analysis Object、Loop signs、工况和 correlation 只接受 `f6-analysis-context-v1`，禁止文本或图片推断。
- 无 confirmed/authorized `f6-optimization-targets-v1` 时不得生成量化 scenario。
- 只有 P0 gap 使最终状态为 `INCOMPLETE`；P1 只把 PASS 降为 `CONDITIONAL_PASS`；P2 不改变状态；可靠 baseline FAIL 必须保留。
- F4 Mean、RSS、WC、Cp/Cpk、Z、DPM、Yield 不得在 F6 中重新实现或替换。
- Correlated mode 在本期为 P0 `correlated_model_not_supported`，不得用独立 RSS 代替。
- F6 继续只发布六个同名文件，全部为 `confidential`，源 workbook 只读。
- 每个生产代码变更必须先有失败测试，并在同一任务内完成 RED/GREEN。
- 每个任务提交前运行 `git diff --check`。
