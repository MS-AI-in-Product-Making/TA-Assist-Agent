# 差异化

> 传统 TA Excel vs. 通用 LLM vs. 专用 TA Agent（本项目）。
> 本工具的价值并非“自动计算”（计算本身复用 Excel），而是将知识库、基于事实的客观解读、数据与图纸的可追溯关联，以及实测 Cpk 闭环结合起来，同时将最终判断留给用户。

## 三方对比（按流程顺序）

各行遵循端到端流程；“阶段”对应 [功能拆分](04-feature-breakdown.md) 中的 Feature ID。

| 阶段 | 维度 | 传统 TA Excel | 通用 LLM | 专用 TA Agent（本项目） |
|:---:|---|---|---|---|
| **F0** | 知识库 | 无，仅存在于工程师经验中 | 无依据、无 grounding | 三类受控知识库（能力/规则/术语）；每项判断可追溯至具体条目 |
| **F2** | 数据清洗 | 手动、易出错 | 无判断依据，只能泛泛而谈 | 检查必填字段，并按能力库校验公差范围和分布，标记“库内/库外”；同时检查 DIM ID 完整性 |
| **F3** | 数据到图纸关联（DIM ID） | 手动、依赖描述、易歧义 | 无法关联 | 通过 DIM ID 唯一关联因子与图纸尺寸（仅标识符，不做图片识别）；按类别分组并定位精确位置；缺失项生成清单；关联可选 ADO 时可在 EV1 等里程碑前提醒负责人 |
| **F5** | 计算 | 模板公式可靠 | 常计算错误、不可复现 | 复用相同 Excel 公式，结果一致且可复现 |
| **F6** | 数据解读 | 依赖个人经验，难标准化 | 无规则、无知识库、一次性回答 | 事实、阈值检查与贡献分解；每条规则判断引用知识库；客观陈述，最终判断由用户做出；不确定时确认，不编造 |
| **F7** | 公差/尺寸链优化 | 手动试错、耗时 | 无法可靠计算 | 均值居中、贡献经济性、RSS 分配与规格反向求解（2–3 个并列方案）；目标超出制程能力时红色告警 |
| **F8** | 实测闭环 | 无，实测数据不回流 | 无 | 按 DIM ID 回填实测 Cpk，对比初始估算，并将能力库条目从经验等级 T3 升级到实测等级 T1；初期从集中存储手动导入，数据越多准确性越高 |
| **F9** | 交互 | 需自行阅读原始 Excel | 仅聊天，无源数据视图 | 左侧只读证据面板，右侧可引用解读；点击可高亮关联内容；源数据从不被静默修改 |
| 全局 | 可扩展性 | 弱，依赖人力 | 弱，不可信 | 强，标准化/高效/可审计 |
| 全局 | 定位 | 计算工具 | 一次性助手 | **客观证据提供者 + 可验证的决策支持** |

> 注：支撑性功能 F1（多工作表解析）和 F4（方法推荐）也有差异，例如并行加速、按规则推荐且同时计算 WC 与 RSS；但它们并非核心差异化来源。

## 一句话总结

> Excel 仅解决“数学是否算对”；通用 LLM 是没有依据的一次性工具。本工具在可靠计算引擎之上加入受控知识库，交付结构化、可复现、可审计的客观解读，通过 DIM ID 关联数据与图纸，并以实测 Cpk 构成闭环；最终判断仍由用户做出，存在疑义时停止并要求确认。
